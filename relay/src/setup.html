Relay

1Connection

Once per computer. TikTok fetches slide images from your public URL, and sends you back there after sign-in.

How to set this up
  1. Run a tunnel to 127.0.0.1:8787 on a subdomain you own, e.g. cloudflared tunnel --url http://127.0.0.1:8787 with a named tunnel on media.yourdomain.com. Paste that URL above.
  2. In the TikTok developer portal, create an app with the Content Posting API, scopes video.upload and video.publish. Add the redirect URI shown after you save, and verify your public URL's domain under URL properties.
  3. Instagram: create a Meta app with Instagram Login, add each account as a tester, and generate a token for it.
